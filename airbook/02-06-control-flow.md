# Управляющие конструкции: когда код начинает принимать решения

Линейные программы скучны
Настоящая магия начинается, когда код смотрит на данные и решает:
"выполнить это" или "пропустить", "повторить пять раз" или "завершиться"
В Rust для этого есть `if`, `loop`, `while` и `for`
Звучит знакомо, но есть ловушки, которые заставят вас скучать по Python

## if -- это выражение, а не инструкция

В большинстве языков `if` это инструкция (statement):
она делает что-то, но не возвращает значение
В Rust `if` это **выражение** (expression), которое вычисляется в значение

```rust
let number = 3;

if number < 5 {
    println!("Меньше пяти");
} else {
    println!("Пять или больше");
}
```

Пока всё как обычно
Но теперь смотрите, как можно присвоить результат `if` переменной:

```rust
let condition = true;
let number = if condition { 5 } else { 6 };
// 5
println!("{}", number);
```

Блок кода после `if` или `else` возвращает последнее выражение (без точки с запятой!)
Здесь `if` работает как тернарный оператор, но читается как человеческий язык

**Важное ограничение:**
oба ветвления должны вернуть одинаковый тип
Такой код не скомпилируется:

```rust
// ОШИБКА!
let number = if condition { 5 } else { "шесть" };
```

Компилятор скажет: "expected integer, found `&str`"
Rust не может в рантайме решить, что за тип в переменной
он должен знать это заранее
Это болезненно, если вы пришли из Python, но спасает от ошибок вида
"неожиданно получил строку вместо числа"

## Нет "truthy" и "falsy" значений

Если вы кодили на JavaScript или Python, привыкли, что `if (1)`
или `if ("строка")` работают как true
В Rust такое не прокатит:

```rust
let number = 3;

if number {
    // ОШИБКА! expected `bool`, found integer
    println!("number is three");
}
```

Условие должно быть строго `bool`
Не число, не строка, не объект -- именно `true` или `false`
Вы должны явно написать:

```rust
if number != 0 { ... }
if !string.is_empty() { ... }
```

Это кажется многословным, пока вы не поймаете баг,
где переменная `count` случайно оказалась 0, а вы думали, что она true
Явное лучше неявного

## else if: цепочка условий

Когда условий много, используйте `else if`
Но будьте осторожны:
Rust выполняет только **первый** подходящий блок и игнорирует остальные

```rust
let number = 6;

if number % 4 == 0 {
    println!("Делится на 4");
} else if number % 3 == 0 {
    // Это выполнится
    println!("Делится на 3");
} else if number % 2 == 0 {
    // Это проигнорируется, хотя 6 делится и на 2!
    println!("Делится на 2");
}
```

6 делится и на 3, и на 2, но мы увидим только "Делится на 3"
Если у вас больше трёх-четырёх `else if`, подумайте о `match`
Эта конструкция мощнее и читабельнее

## Циклы: когда нужно повторить

Часто полезно выполнить блок кода более одного раза
Для этой задачи Rust предоставляет несколько видов *циклов*
Три способа деалать крутки: `loop`, `while` и `for`

## loop: бесконечность не предел

`loop` это просто бесконечный цикл
Никаких условий, никаких проверок, просто крутись, пока не скажут остановиться

```rust
loop {
    println!("Снова!");
    // Ctrl+C, чтобы остановить
}
```

Но у `loop` есть крутая фича: он может возвращать значение через `break`!

```rust
let mut counter = 0;

let result = loop {
    counter += 1;
    
    if counter == 10 {
        // Возвращаем 20
        break counter * 2;
    }
};
// 20
println!("{}", result);
```

Это удобно для операций "пытайся до талго льда"
Например, подключение к серверу:
пытаемся, пытаемся, и когда получилось -- возвращаем результат

## Метки циклов: когда циклы вложены

Если у вас цикл внутри цикла, `break` и `continue` по умолчанию работают с внутренним
Чтобы управлять внешним, используйте метки с одинарной кавычки:

```rust
'outer: loop {
    println!("Внешний цикл");
    
    loop {
        println!("Внутренний");
        // Выходим из обоих!
        break 'outer;
    }
}
```

Метки нужны редко, но когда нужны спасают от костылей с флагами

## while: цикл с условием

Классика: крутимся, пока условие истинно

```rust
let mut number = 3;

while number != 0 {
    println!("{}", number);
    number -= 1;
}
println!("Старт!");
```

Но в Rust есть ловушка:
если вы используете `while` для итерации по массиву через индексы,
то вы делаете это неправильно

## for: король итераций

Не делайте так (даже если это работает):

```rust
let a = [10, 20, 30, 40, 50];
let mut index = 0;

while index < 5 {
    // Опасно!
    // Что если элементов станет 4?
    println!("{}", a[index]);
    index += 1;
}
```

Здесь риск выхода за границы массива,
медленная проверка индекса на каждой итерации,
и вообще это выглядит как код 1980-х

Делайте так:

```rust
let a = [10, 20, 30, 40, 50];

for element in a {
    println!("{}", element);
}
```

Безопасно, быстро, читаемо
`for` перебирает элементы, и компилятор гарантирует, что вы не вылезете за границы

Даже для счётчиков используйте `for` с диапазонами:

```rust
// Обратный отсчёт
for number in (1..4).rev() {
    println!("{}!", number);
}
println!("LIFTOFF!!!");
```

`(1..4)` создаёт диапазон от 1 до 3 (4 не включительно!),
`.rev()` переворачивает его
Это идиоматично для Rust
